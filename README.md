# Fullstack-dasturlash-kursi

SN1 va SN2 kurslaridagi mashqlar.

## Hozirgi mashq: foydalanuvchilar ro'yxati

`fetch` va `async/await` yordamida [dummyjson.com](https://dummyjson.com/users) API'dan foydalanuvchilarni olib,
kartalar ko'rinishida chiqaradi. Yuklanish holati, xatolik va "Qayta urinish" tugmasi bor.
API'dan kelgan matn HTML escape qilinadi.

`script.js` boshidagi izohga olingan kodlar — Promise va `Promise.all` bo'yicha dars yozuvlari.

Ishga tushirish: `index.html` ni brauzerda oching.
